- 2026-09-02 — Lint: `play` output of MessageItemComponent renamed `playRequested` (naming an output like a native DOM event is forbidden); audio player waveform made accessible (role slider + keyboard).
- 2026-09-02 — Lint: removed `autofocus` in sidebar (a11y), TTS regex fixed (`[\*\-\+]` → `[*\-+]`).
- 2026-09-02 — AI: ported Groq chat from portfolio (OpenAI-compatible, fetch without SDK) as alternative provider to Gemini, selectable via `AI_PROVIDER` in `.env`. Gemini remains the default and only provider for audio (TTS + audio input).
- 2026-09-02 — Gemini chat model: `gemini-2.5-flash-preview-09-2025` removed by Google (404 on every chat → frontend console errors). Replaced by `gemini-2.5-flash` (200 verified). TTS `gemini-2.5-flash-preview-tts` still OK. Lesson: ban hardcoded `preview-XX-YYYY` models, they expire.
- 2026-09-02 — Frontend imports: forbidden relative imports 2+ levels deep (`../../`, `../../../`…). Path aliases added in `apps/frontend/tsconfig.json`: `@environment`, `@models/*`, `@core/*`, `@features/*`. 15 imports rewritten. Stale aliases removed from `tsconfig.base.json` (`@app/prisma/*` never used, `@prisma/client → generated/prisma` pointed to a deleted folder).
- 2026-09-02 — SSE migration: Socket.IO gateway removed (dead code). `AiProviderService` centralizes gemini|groq selection. SSE endpoint `POST /api/ai/chat/stream` = full chat path (session + persistence + streaming). Frontend: `MessageService.streamTextMessage()` with GraphQL fallback. Lesson: single provider selection point (avoid duplicated resolver/controller logic).
- 2026-09-02 — Socket.IO: backend gateway identified as dead code (no socket.io-client on frontend). Kept as-is, migration analysis to SSE documented in tasks/01.

- 2026-09-04 — Mobile/recording (tasks/08-mobile): `chat-input` (`isRecording`/`liveToggled`), `chat-page` (`isMobile` + "+" new-chat button), sidebar `X` button removed (collapse `>>` guard).

Decision: migrate STT to Groq `whisper-large-v3-turbo` (free tier, webm supported, auto language detection) via backend endpoint `POST /api/ai/transcribe`; VAD + MediaRecorder client-side; SpeechRecognition kept as fallback (`sttProvider: 'browser'`). - 2026-09-07 — STT & TTS & Angular 19: STT migrated to Groq Whisper `whisper-large-v3-turbo` via `POST /api/ai/transcribe` with Web Speech API fallback. - 2026-09-17 — Dark/Light Design System (Tasks 22–27): daisyUI 5 theme pair frozen on `halloween` (dark, default) and `emerald` (light) declared in `styles.css`. Strict rule: daisyUI semantic tokens only (forbidden arbitrary classes `bg-white`, `bg-black`, `bg-[...]`, `dark:`, `text-gray-*`, `bg-gray-*`, `from-blue`, `text-blue`). Automated guard via `scripts/check-theme-tokens.mjs` wired as prebuild `check-theme-tokens` in `project.json` (blocks build on forbidden tokens). Prettier 2.8 excluded for `sidebar-session-list.component.html`. ThemeService 100% Angular (`provideAppInitializer`, cookies `app_theme`, dynamic `theme-color` swap and PWA manifests).
- 2026-09-17 — Dynamic Conversation Providers (Task 29): unified backend registry `AI_PROVIDERS_REGISTRY` (Groq, Gemini, OpenAI, Anthropic, Mistral, DeepSeek, Qwen) and generic `OpenAiCompatService` adapter. Dynamic discovery via `GET /api/ai/models?provider=` with effective key (user header or .env) and no-key fallback. UI AI Model tab ordered 1. Provider → 2. API Key → 3. Discovered models. Keys managed generically in `ApiKeyService` and propagated in SSE / GraphQL.
- 2026-09-17 — Multi-Provider TTS & STT (Task 30): unified backend registry `TTS_PROVIDERS_REGISTRY` (Azure Speech, Google Cloud TTS, AWS Polly, OpenAI Audio, MiniMax, ElevenLabs, Web Speech browser) with quota, quality and review notes. Router service `TtsProviderService` with endpoints `GET /api/ai/tts-providers`, `GET /api/ai/voices` and `POST /api/ai/tts`. Frontend: `ElevenLabsVoiceService` extended as multi-provider TTS service, dynamic audio preview, dedicated key input per TTS provider, selectable audio models (e.g. OpenAI `tts-1` / `tts-1-hd`) and Whisper STT model selection (`whisper-large-v3-turbo`, `whisper-large-v3`, `distil-whisper-large-v3-en`).

- 2026-09-17 — Server Default Key UX: explicit affordance for server key mode in AI Model and Voices tabs. When no custom key is entered: `badge-neutral` "Server default" badge visible. - 2026-09-17 — Anti-slop & UI Dialog Fixes:
  1. Selectors: removed double native/daisyUI arrow via global CSS rule `select.select { appearance: none; -webkit-appearance: none; -moz-appearance: none; }` in `styles.css`.
  2. TTS & AI Providers: cleaned emoji stars (`⭐⭐⭐⭐⭐`) and text reviews in backend and frontend registries. Replaced by clean professional quality labels (`Neural HD`, `Fluid Neural`, `Expressive`, etc.).
  3. "Server Default" Option: explicit `default` option added in provider selects for AI and TTS to use server configuration.
  4. Conditional Model & Voice Display: if a third-party provider requiring API key is selected without user-entered key, model and voice lists are hidden and replaced by a clean invitation card prompting to enter key or switch to default server mode.
  5. Dark & Light Themes: preview cards faithfully integrate `halloween` (dark) and `emerald` (light) themes with their respective daisyUI semantic tokens.
  6. Typography & Font-size: removed view duplication; cursor and custom input only appear when "Custom" mode is selected.
- 2026-09-18 — Angular Modern Migration: total removal of `FormsModule`, `CommonModule`, `ngModel`, `ngClass` from frontend.
  1. **FormsModule** removed from 7 components that imported it (`sidebar-search-modal`, `chat-input`, `tts-tester`, `settings-tab-general`, `settings-tab-ai`, `settings-tab-voices`, `chat-page`). Replacement pattern: `[ngModel]="signal()" (ngModelChange)="setter($event)"` → `[value]="signal()" (input)="setter($any($event.target).value)"`.
  2. **app-select** refactored: `input()` + `output()` for `value` replaced by `model()` (Angular 20.3). `ControlValueAccessor` removed (useless without FormsModule). Consumers migrated to `[(value)]="signal()"`.
  3. **CommonModule** removed from 17 standalone components. No `*ngIf`, `*ngFor`, `*ngSwitch`, `async`, `json`, `date` pipes used in templates — project already uses `@if`/`@for`/`@switch`. Only `DOCUMENT` (token) imported directly from `@angular/common` in `chat-container.component.ts`.
  4. **ngClass** migrated to `[class]` in `select.component.ts` (`[ngClass]="sizeClasses()"` → `[class]="sizeClasses()"`).
  5. Rules added in `.agents/rules/stack.md`: forbidden FormsModule, ReactiveFormsModule, CommonModule, ngClass, ngStyle. Replacement patterns documented. Mandatory use of `model()` for two-way binding in custom components.
  6. Build validated (`nx run frontend:build` = success). 1 pre-existing lint error (accessibility `click-events-have-key-events` in `message-item`) unrelated to this migration.
