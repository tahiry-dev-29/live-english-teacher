# Décisions d'architecture (append-only)

- 2026-09-02 — pnpm : placeholders `allowBuilds` invalides remplacés par des booléens ; `@prisma/cli@2.20.1` (package dépréqué, preinstall qui échoue) mis à `false` dans `allowBuilds` au lieu d'être retiré des deps. Leçon : ne pas modifier les versions pour contourner un échec de script.
- 2026-09-02 — Prisma : suppression du `output = "../generated/prisma"` du schema → génération dans le chemin par défaut. Cause : le code importe `@prisma/client` (chemin par défaut) et le postinstall auto-generate échoue à cause de `@prisma/cli@2.20.1`. C'était le crash du backend (`@prisma/client did not initialize yet`).
- 2026-09-02 — Lint : output `play` de MessageItemComponent renommé `playRequested` (interdit de nommer un output comme un event DOM natif) ; waveform du player audio rendue accessible (role slider + clavier).
- 2026-09-02 — Lint : suppression de `autofocus` dans sidebar (a11y), regex TTS corrigée (`[\*\-\+]` → `[*\-+]`).
- 2026-09-02 — IA : port du chat Groq du portfolio (OpenAI-compatible, fetch sans SDK) comme provider alternatif à Gemini, sélectionnable via `AI_PROVIDER` dans `.env`. Gemini reste le défaut et le seul provider pour l'audio (TTS + audio input).
- 2026-09-02 — Modèle Gemini chat : `gemini-2.5-flash-preview-09-2025` retiré par Google (404 sur chaque chat → erreurs console frontend). Remplacé par `gemini-2.5-flash` (200 vérifié). TTS `gemini-2.5-flash-preview-tts` toujours OK. Leçon : bannir les modèles `preview-XX-YYYY` en dur, ils expirent.
- 2026-09-02 — Imports frontend : interdiction des imports relatifs à 2+ niveaux (`../../`, `../../../`…). Path aliases ajoutés dans `apps/frontend/tsconfig.json` : `@environment`, `@models/*`, `@core/*`, `@features/*`. 15 imports réécrits. Aliases périmés supprimés du `tsconfig.base.json` (`@app/prisma/*` jamais utilisé, `@prisma/client → generated/prisma` pointait vers un dossier supprimé).
- 2026-09-02 — Migration SSE : gateway Socket.IO supprimée (code mort). `AiProviderService` centralise la sélection gemini|groq. Endpoint SSE `POST /api/ai/chat/stream` = chemin chat complet (session + persistance + streaming). Frontend : `MessageService.streamTextMessage()` avec fallback GraphQL. Leçon : un seul point de sélection de provider (éviter la logique dupliquée resolver/controller).
- 2026-09-02 — Socket.IO : gateway backend identifiée comme code mort (aucun socket.io-client côté frontend). Conservation en l'état, analyse de migration vers SSE documentée dans tasks/01.
- 2026-09-04 — SSE complet (tasks/04+09) : `live.gateway.ts` + `dto/live-input.dto.ts` supprimés, deps directes socket.io retirées de `package.json` (reste peers optionnels transitifs dans le lockfile) ; `MessageService.streamViaSSE()` + fallback GraphQL, `VoiceCallService` reste client-side (VAD/SpeechRecognition). Zéro réf socket.io dans `apps/frontend` + `libs/backend`.
- 2026-09-04 — Warnings (tasks/05) : 23 → 0, types dédiés `SpeechRecognitionLike` + `SpeechSynthesisErrorEvent`, Apollo générique `query<T>`/`mutate<T>`, timers `ReturnType<typeof setTimeout>`, `implements OnDestroy`.
- 2026-09-04 — UI daisyUI (tasks/06) : thème `halloween` par défaut (`@plugin daisyui` + `data-theme` sur `<html>` vérifiés), 14 composants en sémantique `btn`/`card`/`modal`/`menu`/`chat` ; couleurs custom bannies.
- 2026-09-04 — Mobile/recording (tasks/08-mobile) : `chat-input` (`isRecording`/`liveToggled`), `chat-page` (`isMobile` + bouton "+" new-chat), sidebar bouton `X` supprimé (garde collapse `>>`).
- 2026-09-04 — Sécu (tasks/07) : audit thr-cyber documenté (12 findings), hardening NON appliqué — `enableCors()` wildcard toujours en place, pas de `helmet`/`throttler` ; `introspection` prod déjà off. Décision auth/CORS en attente.
- 2026-09-04 — Groq E2E (tasks/08-e2e) : en attente `GROQ_API_KEY` utilisateur, non testé ; tasks/10-14 (OnPush/signaux) créées TODO.
- 2026-09-04 — STT (task 15 créée TODO) : reconnaissance vocale du live mode trop dépendante du navigateur (`webkitSpeechRecognition` = serveurs Google ; cassée sous Chromium/Linux sans clé, Firefox disabled, Edge non supporté). Décision : migrer le STT vers Groq `whisper-large-v3-turbo` (free tier, webm supporté, auto-détection langue) via endpoint backend `POST /api/ai/transcribe` ; VAD + MediaRecorder côté client ; SpeechRecognition conservé en fallback (`sttProvider: 'browser'`). TTS reste Web Speech API (Groq playai-tts = EN uniquement).

- 2026-09-07 — STT & TTS & Angular 19 : STT migré vers Groq Whisper `whisper-large-v3-turbo` via `POST /api/ai/transcribe` avec fallback Web Speech API. TTS migré vers ElevenLabs avec fallback Web Speech, 8 voix gratuites exposées via `GET /api/ai/voices` avec aperçu audio en direct dans le dialogue de configuration.
